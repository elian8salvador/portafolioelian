# Portfolio · Elian Salvador

Mi portfolio personal: quién soy, mi experiencia, lo que he trabajado en ASIX (perfil de ciberseguridad) y algunos proyectos.

**Web:** https://elian8salvador.github.io/portafolioelian/

## Sobre el proyecto

Web estática hecha con HTML, CSS y JavaScript, sin frameworks, y publicada con GitHub Pages. El contenido se carga desde un único archivo de datos, así que actualizarlo no requiere tocar el código.

## Estructura

- `index.html`: la página
- `data/data.js`: el contenido (perfil, experiencia, áreas del curso y proyectos)
- `assets/`: estilos, scripts e imágenes
- `docs/`: documentación de mis prácticas

## Verlo en local

Descarga el repositorio y abre `index.html` en el navegador. No hace falta instalar nada.
